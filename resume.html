О себе

Разрабатываю телеграм-ботов, парсеры и скрипты автоматизации на Python: интеграция с внешними API, сбор данных с сайтов, базы данных, задачи по расписанию, деплой на сервер как сервис с автозапуском. Довожу задачи до рабочего состояния, читаю чужой код и документацию, не боюсь железа.

Проекты

Система управления квест-комнатой — github.com/agladcenko/quest-control-system

Коммерческий проект для действующей квест-комнаты. 4 программы на Python/Pygame: управление 16 замками через ESP32/Arduino по HTTP, освещение по зонам, интерактивные панели для игроков. Многопоточность, мягкая деградация при отказе оборудования.

Бот напоминаний о повторяющихся делах — github.com/agladcenko/reminder-bot

Telegram-бот на aiogram 3: планировщик с автопереносом сроков, часовые пояса пользователей, сохранение задач между перезапусками. Диалог создания события на конечном автомате с валидацией ввода.

Парсер цен Steam Market — github.com/agladcenko/Steam-endpoint-parser

Сбор цен двумя способами: через JSON-эндпоинт и разбором HTML-страницы с server-side rendering. Обработка лимитов запросов, повторные попытки, выгрузка в Excel с числовыми форматами.

Симулятор баллистической траектории — github.com/agladcenko/ballistic-trajectory

C++17 + SFML, метод Рунге-Кутты 4-го порядка с учётом сопротивления воздуха, интерактивные графики. ~5300 строк, учебная практика по чёткому ТЗ.

Называю срок и придерживаюсь его, показываю промежуточный результат, а не пропадаю до сдачи. Сдаю рабочий код с инструкцией по запуску. Если задача мне не по силам или требует больше времени, чем изначально выглядело — говорю об этом сразу, а не по факту срыва срока.
